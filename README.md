# JellyDesk

Nativer Jellyfin-Client für Windows im Apple-Liquid-Glass-Design, mit Jellyseerr-Integration, Offline-Downloads, SyncPlay, lokalem Cache und Per-User-Installer ohne Admin-Rechte.
